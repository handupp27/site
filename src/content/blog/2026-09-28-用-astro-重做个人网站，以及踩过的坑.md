## 起因

想给自己做个网站放项目和笔记。最初的版本是一个 index.html，

内容全嵌在文件里，改一次就要重新导出覆盖一次。发一篇文章的成本

比写它还高。

## 选型

考虑过四条路：

- **GitHub API 列目录** — 传 1 个文件就能发，但做不到每篇独立网址
- **index.json 手工清单** — 传文件 + 改一行，同样没有独立网址
- **GitHub Actions 构建** — 能被搜到，但等于手写一个简陋版 Astro
- **Astro** — 能被搜到，社区成熟，最后选了它

前两个做不到每篇独立网址，这是架构决定的硬限制。第三个等于

手写一个简陋版 Astro。最后选了 Astro。


## 踩的坑

**PATH 不刷新。** 装完 GitHub CLI，已打开的终端里 `gh` 仍然找不到。关掉重开就好，但当时排查了十分钟。

**git remote add 不会建仓库。** 它只在本地记下地址。远程那个得自己去建，否则 push 报 `Repository not found`。

**workers.dev 在国内不通。** 用 tcptest 测，全国几乎全红。换成自有域名后大部分节点恢复 200。

## 结果

- `handupp27.com` — 站点
- `handupp27.com/admin/` — 可视化后台
- `me@handupp27.com` — 域名邮箱转发

push 自动构建，后台发文也自动上线。
